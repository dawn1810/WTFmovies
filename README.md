# WTF Movies

> Website xem phim trực tuyến: xem, bình luận, đánh giá phim, kèm trang quản trị nội dung.

Dự án nhóm. Người dùng xem phim, để lại bình luận và đánh giá; quản trị viên quản lý người dùng, bình luận và đăng tải phim mới.

## Tính năng

**Người dùng**
- Duyệt và xem phim trực tuyến
- Bình luận và đánh giá
- Tài khoản cá nhân

**Quản trị**
- Quản lý người dùng
- Quản lý bình luận
- Đăng tải và quản lý phim

## Công nghệ

- **Next.js + TypeScript**
- Công cụ phụ trợ tải video lên (TikTok / YouTube) trong `TiktokVideosUpload/`, `YoutubeVideoUpload/`

Sơ đồ ERD có trong `ERDDiagram.svg`; danh sách chức năng trong `Chuc nang he thong.xlsx`.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở http://localhost:3000.
